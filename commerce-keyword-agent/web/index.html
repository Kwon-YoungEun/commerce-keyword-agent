설정

네이버 검색 API 키를 넣으면 스토어 미리보기가 상품 카드로 바뀝니다.

네이버 API 키 발급 방법
  1. developers.naver.com 애플리케이션 등록 으로 이동합니다.
  2. 애플리케이션 이름을 적고, 사용 API 에서 검색 을 고릅니다.
  3. 환경 추가에서 WEB 설정 을 고르고 http://127.0.0.1:8765 를 넣습니다.
  4. 등록하면 나오는 Client ID / Client Secret 을 위에 붙여 넣고 저장합니다.
